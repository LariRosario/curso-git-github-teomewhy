ls -> abre a pasta e lista o que h  
cd -> muda de diret rio
pwd -> mostra o caminho absoluto
mkdir -> cria uma pasta nova
ctrl + L -> limpa a tela
cat -> mostra o conteudo do arquivo
rm -rf -> remove de forma recursiva e for ada todos os diret rios
git status -> mostra o que acontece no diret rio
git add -> adiciona o que vai para o commit
git add* -> adiciona todos os arquivos do projeto para commitar
git add . -> adiciona todos os arquivos da pasta atual para commitar
git diff -> mostra a diferença do estado atual do arquivo em relação ao commit anterior


## FLUXO DE TRABALHO
1. criar o diretório (pasta) do projeto
2. iniciar o git dentro do diretório criado (git init .)
3. edita ou cria arquivos
4. git status
5. git add <nome_arquivo>
6. git status
7. git commit -m "mensagem"
8. git status
9. volta ao passo 3
